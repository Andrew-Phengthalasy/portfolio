# Andrew Phengthalasy — Portfolio

My personal portfolio website! 

Stack
Framework: Next.js 
Styling: Tailwind CSS 
Icons: Lucide React + React Icons
Fonts: Cormorant Garamond, DM Sans, JetBrains Mono 
Deployment: Vercel

How to run: 

# Clone the repo
git clone https://github.com/Andrew-Phengthalasy/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run dev server
npm run dev

Open http://localhost:3000 to view locally.
